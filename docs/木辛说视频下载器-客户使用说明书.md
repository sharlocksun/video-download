# 木辛说视频下载器客户使用说明书

**适用系统：** Windows 10/11 64 位、macOS 11 及以上（Intel 与 Apple Silicon）  
**适用版本：** 0.1.0  
**主要用途：** 下载公开视频、获取字幕、语音转文字、字幕整理与翻译、视频内容分析和多平台内容创作。

> 本软件只用于下载、整理和分析您有权保存和使用的内容。请遵守视频平台规则、版权要求及当地法律。

## 1. 六步快速开始

1. 安装并启动“木辛说视频下载器”。
2. 在“视频来源”中选择链接所属平台。
3. 将视频链接粘贴到“视频链接”框；批量下载时每行填写一个链接。
4. 选择画质和保存目录，点击“开始下载”。
5. 下载完成后，在“内容创作助手”中点击“最近下载”，再点击“获取视频文字”。
6. 需要总结、改写或创作内容时配置 AI 接口；只下载视频或使用本地 Whisper 转写时不需要配置 API。

## 2. 支持的平台和主要能力

| 平台 | 视频下载 | 平台字幕 | 登录用途 |
|---|---:|---:|---|
| 抖音 | 支持视频、图片和图集，尽量下载无水印媒体 | 视平台是否提供 | 通常不需要 |
| Bilibili | 支持 | 视视频是否提供 | 登录后可尝试高码率、1080P+ 或 4K |
| YouTube | 支持 | 支持率较高 | 登录可用于受限内容或高质量格式 |
| 快手 | 支持视频、图片和图集；公开作品优先接口直下 | 视平台是否提供 | 通常不需要 |
| 小红书 | 支持视频、图片笔记和图集 | 视平台是否提供 | 通常不需要 |
| TikTok | 支持视频和图片轮播，尽量下载无水印媒体 | 视平台是否提供 | 部分内容可能需要 |
| Instagram | 支持视频、图片和混合轮播 | 视平台是否提供 | 触发登录或机器人验证时使用 |

平台没有提供字幕不代表软件故障。此时可先下载视频，再让本地 Whisper 从声音识别文字。

## 3. 安装与首次启动

### 3.1 Windows

1. 双击 `木辛说视频下载器-Setup-x64.exe`。
2. 按安装向导选择安装目录，并决定是否创建桌面快捷方式。
3. 如果 Windows SmartScreen 显示“Windows 已保护你的电脑”，确认文件来自正式交付渠道并校验 SHA-256 后，点击“更多信息”→“仍要运行”。
4. 安装完成后，从桌面或开始菜单启动程序。

Windows 版不要求客户预装 Node.js、Python、FFmpeg、yt-dlp 或 Deno。

### 3.2 macOS

1. 双击 `木辛说视频下载器-macOS-universal.dmg`。
2. 将“木辛说视频下载器”拖入 `Applications`（应用程序）文件夹。
3. 当前版本尚未经过 Apple 公证。首次启动时，如果系统阻止打开，请在 Finder 的“应用程序”中右键软件图标，选择“打开”，再确认一次。
4. 软件同时支持 Intel Mac 和 Apple Silicon Mac。

macOS 版不要求客户预装 Node.js、FFmpeg、yt-dlp、Deno 或 Whisper 引擎。

### 3.3 首次启动建议

- 点击“环境与组件”，确认 yt-dlp、FFmpeg 和 Deno 显示可用。
- 只下载视频时，不需要安装 Whisper 模型，也不需要配置 AI。
- 第一次需要语音转文字时，再选择并下载 Whisper 模型。
- 默认保存目录可以直接使用，也可以在每次下载前自行修改。

## 4. 下载视频

### 4.1 单个视频

1. 在“视频来源”选择正确平台。
2. 粘贴完整视频链接。
3. 选择“画质偏好”。不确定时选择“最佳可用画质”。
4. 如需确认平台实际提供的格式，点击画质右侧的“识别”。
5. 检查保存目录与文件名规则。
6. 点击“开始下载”，在右侧状态和任务日志中查看进度。

下载完成后，链接不会自动清空，方便继续识别字幕、重新下载或调整画质。

### 4.2 批量下载

- 每行粘贴一个链接。
- 批量任务会依次进入队列。
- 建议文件名模板保留 `%title%` 或 `%id%`，避免不同视频使用相同文件名。
- “覆盖同名文件”未勾选时，软件会为重复文件自动生成新名称。

### 4.3 画质选择

- **最佳可用画质：** 自动选择平台可提供的最佳组合。
- **4K / 2K / 1080P+：** 平台可能要求登录，也可能只提供无声视频流，软件会使用 FFmpeg 合并视频和音频。
- **720P / 540P / 480P / 360P：** 适合控制文件大小或网络较慢的情况。
- **最小文件：** 优先节省空间，不保证清晰度。

如果所选画质不存在，先点击“识别”查看实际格式，或改用“最佳可用画质”。

快手会按照公开接口实际返回的清晰度下载，不会把视频主动压缩为 720P。有些作品最高只提供 720P，另一些作品会提供 1080P。横屏 1080P 可能显示为 1440×1080，竖屏通常为 1080×1920。

### 4.4 图片、图集和混合内容

- 可以直接粘贴平台链接，也可以粘贴包含链接的完整分享文案。
- 抖音、快手、小红书和 TikTok 的图片作品会保存原图，并自动生成便于预览的相册 MP4。
- Instagram 混合轮播会把原图和原始视频放在同一个作品文件夹中。
- TikTok 图片轮播会保留背景音乐；背景音乐不可用时仍会保存原图并生成无声相册视频。
- 每个作品会建立独立文件夹，常见文件名为 `图片_01.jpg`、`图片_02.jpg`、`视频_01.mp4` 和作品同名相册视频。
- 重复下载且未开启覆盖时，会自动建立带 `_1`、`_2` 后缀的新文件夹。

快手公开作品优先通过接口获取媒体地址，不会打开或跳转浏览器页面。只有接口不可用、作品要求登录或触发安全验证时，软件才会打开并复用一个快手窗口作为回退。

TikTok 在识别画质或图集后会暂时锁定当前媒体结果，正式下载时不再重复解析页面。媒体地址过期时软件会自动重新获取。

### 4.5 终止任务与退出

- 点击“终止下载”会终止当前下载并清理队列。
- 点击页面右上角“退出程序”会关闭界面和后台进程。
- 不建议在音视频合并阶段直接强制结束系统进程，否则可能留下未完成的临时文件。

## 5. 平台登录

### 5.1 Bilibili 高码率登录

1. 选择 Bilibili。
2. 点击“高码率登录”。
3. 在打开的浏览器窗口完成登录。
4. 返回软件点击“读取登录状态”。

普通画质通常不需要登录。只有需要高码率、1080P+ 或 4K 时再登录。

### 5.2 YouTube 与 Instagram

1. 将“登录来源”设为“本程序登录窗口”。默认值是“不使用登录状态”。
2. 选择 Chrome、Edge 或 Firefox。
3. 点击“打开 YouTube 登录”或相应平台登录按钮。
4. 在唯一的登录窗口中完成登录，不需要关闭您平时已经打开的网页。
5. 返回软件点击“确认登录来源”。

软件只读取本程序登录窗口的状态，不会主动关闭您日常使用的浏览器页面。一个平台只会复用一个登录窗口。

## 6. 获取视频文字

### 6.1 推荐操作：获取视频文字

下载完成后，点击“最近下载”，确认本地视频路径已自动填入，然后点击“获取视频文字”。软件会依次尝试：

1. 获取平台公开字幕。
2. 检查已下载视频中是否包含内嵌字幕轨道。
3. 如果仍然没有字幕，使用本地 Whisper 从音轨转写。
4. 按“最终输出格式”完成中文、英文或中英双语整理。
5. 自动保存原始字幕和最终整理稿。

### 6.2 三种文字来源的区别

- **平台字幕：** 视频平台提供的字幕文件，速度最快，但并非所有视频或平台都有。
- **内嵌字幕：** 已下载视频文件内部包含的字幕轨道。它不能识别直接印在画面上的硬字幕。
- **Whisper 转文字：** 从视频或音频的声音重新识别文字，适用于没有平台字幕和内嵌字幕的情况，耗时取决于视频长度、模型和电脑性能。

### 6.3 字幕语言和输出格式

“AI 设置”中的“视频文字偏好”控制最终结果：

- **字幕获取优先级：** 决定先寻找中文、英文或全部平台字幕。
- **简体中文：** 英文原文在已配置 AI 时可翻译为简体中文。
- **中英双语：** 按同一时间段输出“一句中文 + 一句英文”，而不是把两种语言分成两套时间轴。
- **保持字幕原文：** 不强制翻译或改变原始语言。

如果需要翻译、AI 修正或双语生成，请先配置可用的 AI 接口。没有 API 时仍可保存平台原文、内嵌字幕或 Whisper 原始转写。

### 6.4 Whisper 模型选择

| 模型 | 下载大小 | 特点 | 建议用途 |
|---|---:|---|---|
| small | 约 465 MB | 速度较快、资源占用较低 | 普通电脑、短视频、首次使用 |
| medium | 约 1.5 GB | 中文和英文准确度更高 | 长视频、正式字幕、配置较好的电脑 |
| large-v3 | 约 3.0 GB | 效果优先、占用最高 | 高质量要求和高性能电脑 |

安装步骤：打开“环境与组件”，点击相应模型按钮，等待下载、校验和安装完成。模型安装后可断网转写。

“转写引擎”建议保持“自动选择（优先用户配置）”：

- 如果用户配置了可运行的 Python Whisper/CUDA，软件优先使用该引擎。
- 用户配置不可用时，自动回退到内置 whisper.cpp。
- Windows 客户版默认可使用内置 CPU 引擎；macOS 版内置 universal CPU 引擎。

### 6.5 高级工具

- **只提取平台字幕：** 只检查平台公开字幕，不使用本地视频和 Whisper。
- **只提取内嵌字幕：** 只导出本地视频内部的字幕轨道。
- **Whisper 转文字：** 跳过平台字幕，直接从本地视频或音频识别。
- **提取音频：** 将视频音轨保存为独立音频文件。
- **整理文稿：** 去除时间戳、编号、标签和重复行，得到适合阅读和分析的纯文本。
- **AI 修正字幕：** 先修正原始语言中的错字、断句和标点，再按需要翻译；需要配置 AI。

## 7. AI 设置

本地下载、平台字幕、内嵌字幕、音频提取和 Whisper 转写不需要 API。以下功能需要 API：字幕翻译、AI 修正、深度分析、内容改写和对话创作。

### 7.1 OpenAI 兼容或中转站

1. 接口类型选择“OpenAI 兼容 / 中转站”。
2. 填写服务商提供的模型名称。
3. 填写 API 地址。通常是服务商给出的基础地址，例如以 `/v1` 结尾；不要自行添加聊天接口路径，除非服务商明确要求。
4. 填写 API Key。
5. 点击“保存配置”，再点击“测试连接”。

不同中转站支持的模型和地址格式不同，应以服务商后台说明为准。聊天接口可用不代表音频转写接口可用；本软件默认使用本地 Whisper，不需要中转站提供 `/audio/transcriptions`。

### 7.2 Gemini 与 Anthropic

选择对应接口类型，并按服务商控制台提供的模型名称、API 地址和 Key 填写。测试连接成功后再使用内容创作功能。

### 7.3 常用参数

- **创造性 0.2-0.4：** 更稳定，适合摘要、事实整理和字幕修正。
- **创造性 0.6：** 默认值，兼顾稳定与表达。
- **创造性 0.8-1.0：** 更发散，适合标题、脚本和创意方向。
- **最大输出：** 结果被截断时适当增大；数值越大，API 消耗通常越高。
- **生成超时：** 长字幕或较慢中转站可调到 180-300 秒。

API Key 会保存在本机。Windows 使用当前用户 DPAPI 加密；macOS 使用系统钥匙串。

## 8. 内容创作助手

### 8.1 使用内置模板

1. 在“目标发布平台”选择抖音、Bilibili、YouTube、小红书、快手、TikTok、Instagram 或通用分析。
2. 确认“参考视频链接”和字幕框内容正确。
3. 点击对应的一键模板进行摘要、标题、脚本、结构、亮点或平台化改写。
4. YouTube 模板可用于中文和英文内容；最终语言也可以在对话中明确指定。

模板会根据目标平台调整表达重点。选择平台的目的是告诉 AI 最终内容要发布到哪里，并不限制原视频来自哪个平台。

### 8.2 自定义模板

1. 点击“新增自定义模板”。
2. 填写按钮标签，例如“生成三段式口播”。
3. 填写完整提示词，明确输出结构、语气、长度、受众和语言。
4. 点击“保存模板”。

已有模板也可以编辑提示词或恢复默认。自定义模板只保存在当前电脑上。

### 8.3 与 AI 对话

- 在右下角输入框直接追问、改写或补充要求。
- 按 `Enter` 发送，按 `Shift + Enter` 换行。
- 发送后输入框会清空，历史消息保留在对话区。
- AI 内容会实时显示；生成期间可以正常滚动页面。
- 点击“清空创作记录”只清空当前对话，不会删除字幕和已经导出的文件。

### 8.4 导出创作内容

点击“导出创作内容”，软件会同时生成 Markdown 和 TXT 文件。导出内容只包含有效创作结果，不包含“生成成功”“请求失败”等界面状态提示，也不会把用户输入的提示词混入正文。

## 9. 文件保存位置和目录结构

### 9.1 默认视频目录

- **Windows 安装版：** 安装目录下的 `videos` 文件夹；如果目录不可写，会自动回退到用户“视频”目录。
- **macOS：** `~/Movies/木辛说视频下载器`。

用户可以在“保存目录路径”中为当前下载任务指定其他目录。

### 9.2 字幕和分析资料

每个视频会建立独立资料目录，避免不同视频的文件混在一起。常见子目录包括：

- `01_platform_original`：平台原始字幕。
- `02_embedded_original`：视频内嵌原始字幕。
- `03_whisper_original`：Whisper 原始转写。
- `05_ai_fixed`：AI 修正后的字幕。
- `05_final`：最终整理稿，包括中文、英文和中英双语版本。
- `audio`：提取出的音频。
- `ai`：内容创作助手导出的 Markdown 和 TXT。

选择中英双语并导出整理稿时，软件会尽量同时保存中文字幕、英文字幕和中英混合字幕，便于后续剪辑和二次创作。

### 9.3 图片和图集目录

图片作品不会与普通视频散乱堆放。软件会按作品标题和 ID 建立独立文件夹，其中可能包含：

- `图片_01.jpg`、`图片_02.jpg`：平台返回的原始图片。
- `视频_01.mp4`：混合轮播中的原始视频。
- `作品标题_作品ID.mp4`：根据图片和背景音乐生成的相册视频。

如果 FFmpeg 不可用，原图仍会正常保存，但无法生成相册视频。

## 10. 常见问题

### 下载的视频没有声音

- 确认“环境与组件”中的 FFmpeg 可用。
- 重新选择“最佳可用画质”下载。
- 不要在音频下载或合并阶段强制关闭程序。
- 如果平台只返回无声视频流，软件必须成功下载音频流并完成合并后才会有声音。

### 识别画质提示 Requested format is not available

所选画质在该视频中不存在。点击“识别”查看格式，或改用“最佳可用画质”。

### YouTube 提示 429 Too Many Requests

这是平台访问频率限制。等待一段时间后重试，减少连续识别次数，必要时使用本程序登录窗口。登录不能保证解除平台限流。

### Instagram 提示登录或机器人验证

选择“本程序登录窗口”，完成 Instagram 登录并确认登录来源，然后重新识别或下载。

### 快手为什么只显示 720P

软件会列出快手公开接口实际提供的清晰度。部分作品的原始公开媒体源最高就是 720P；提供 1080P 的作品会显示并下载 1080P。软件不会把 1080P 主动压缩为 720P。

### 快手为什么打开浏览器

公开视频和图集会优先通过接口直接处理，不应打开网页。只有接口失效、作品需要登录或平台要求安全验证时，软件才会打开一个快手窗口，并在后续任务中复用该窗口。

### TikTok 图片链接提示 Unsupported URL

新版会直接解析 TikTok 图片轮播，不再把 `/photo/` 链接交给 yt-dlp。先点击“识别”可以锁定图片和背景音乐；直接下载也会使用多个页面入口自动重试。

### 平台字幕获取失败

平台可能没有公开字幕。先下载视频，再点击“获取视频文字”，软件会继续检查内嵌字幕并使用 Whisper。

### Whisper 安装失败或一直为 0%

- 检查网络、代理和剩余磁盘空间。
- 重新点击相同模型，软件会尝试继续下载。
- 模型较大，medium 和 large-v3 需要更长时间。
- 如果仍失败，点击“重新检测”确认引擎状态。

### Whisper 很慢

- CPU 转写长视频可能需要较长时间，并不一定是卡住。
- 先使用 small 模型测试。
- Windows 用户如自行配置了可用的 CUDA Python Whisper，可将转写引擎设为“自动选择”或“用户配置的 Python Whisper / CUDA”。

### AI 测试连接成功，但生成失败

- 检查模型名称是否与中转站支持的名称完全一致。
- 增加“生成超时”。
- 减少一次发送的字幕长度。
- 确认账户余额、模型权限和中转站限额。
- 某些服务只兼容测试请求，但不完整支持流式输出或长文本。

### macOS 无法打开应用
